# 🚚 Controle de Entregas

Sistema web para controle de serviços e gastos diários.

## ✨ Funcionalidades
- Login de usuário
- Cadastro de serviços
- Cadastro de gastos
- Controle diário com resumo
- Saldo atual e saldo com descontos

## 🛠️ Tecnologias
- HTML5
- CSS3
- JavaScript
- Supabase (banco de dados)

## 🚀 Como rodar
1. Clone o repositório
2. Abra o `index.html` com Live Server
3. Faça login (usuário e senha provisórios)
